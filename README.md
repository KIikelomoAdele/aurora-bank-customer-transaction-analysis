# Aurora Bank Customer & Transaction Analysis

## 📌 Project Overview
This project explores customer and transaction data from Aurora Bank to uncover insights into transaction performance, customer behaviour, transaction risk and banking operations.

The analysis was conducted to identify patterns within banking transactions, assess transaction completion rates, examine risk distribution and provide insights that could support data-driven decision-making.

## 🎯 Project Objectives
- Analyse banking transaction performance.
- Evaluate transaction completion rates.
- Examine transaction risk distribution.
- Explore customer transaction behaviour.
- Identify patterns and insights that can support operational and strategic decisions.

## 📊 Key Metrics
- **Total Customers:** 2,000
- **Total Transactions:** 157,224
- **Total Transaction Value:** $6.87M
- **Completed Transactions:** 98.26%

## 🔍 Key Areas of Analysis
- Transaction status and performance
- Transaction value and volume
- Customer transaction patterns
- Transaction risk analysis
- Banking operational insights

## 🛠️ Tools Used
- Microsoft Excel
- Power BI

## 📈 Key Findings
- Approximately 98.26% of transactions were completed.
- Approximately 66% of transactions fell within the low-risk category.
- High-risk transactions accounted for approximately 1.6% of the transactions analysed.

## 💡 Project Outcome
The analysis provided an overview of transaction performance, customer activity and risk distribution, highlighting patterns that can inform banking operations, transaction monitoring and business decision-making.
